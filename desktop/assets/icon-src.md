# 图标源图说明

- icon-src.png：完整版，1024×1024，透明底。由 Codex 照 plugin/icon.png（插件版图标：米饭碗 + 鲸鱼脸 + 鲸鱼尾巴 + 金点）重画，2026-11-08。
- icon-src-simple.png：简化版，去掉金点和米粒高光，供 24/32/48 像素用。
- icon-src-ultra.png：超简剪影版，只留碗和尾巴，供 16 像素用。
- 生成脚本：	mp/icon-gen/build-icons.py（不在仓库里），用 	auri icon 生成大尺寸 + Pillow 拼多尺寸 ico。

三版都从同一套设计来，缩小时切换不会换形象。
