# 桌面挂件 v0.1.5

2026-11-10 · Windows x64 · 安装包内部版本 0.2.5。DSH 插件仍为 v0.3.3，本次不更新插件包。

## 新增与改善

- **按需隐藏人物**：关闭「加载人物动画」后保留鱼粮和账目，释放视频资源；重新打开时保留原来的人物大小。
- **三主题账目与设置页**：深色、浅白、暗金统一排版，账目内容更清楚；设置页自动保存，较矮屏幕可滚动。鱼粮栏保留原有字号和配色。
- **隐藏人物也能右键设置**：右键鱼粮金额、状态文字或账目卡可直接打开设置；去掉鱼粮栏的金额解释悬停提示。左键仍用于收起/展开账目。

## 修复

- **绿色提示跟随角位变化**：例如 `1.19 → 1.20` 时变绿1.6秒，`1.20 → 1.23` 不再重新触发。判断与显示金额的四舍五入一致；扣费后补回工资也遵循这一规则，冻结期间保持红色。
- 修复大金额切换正负号时可能停止刷新的问题。
- 修复设置页深色背景、人物开关禁用范围，以及打开设置时保存参数可能影响窗口尺寸的问题。
- 错误提示移到鱼粮上方，避免遮挡账目。

## 下载与更新

- `SalaryMeter.exe`：免安装版。
- `SalaryMeter-Setup.exe`：安装版。
- `SHA256SUMS.txt`：两个文件的 SHA-256 校验值。

更新前退出旧挂件，再替换程序或运行安装包。现有配置和账目继续使用；无需修改系统设置。

## 验证与边界

通过三主题×人物显示/隐藏×账目收展的12状态检查、设置交互、金额角位/四舍五入/负余额/扣费冻结检查，以及拖动、命中区、逐位滚动和Rust单元测试。

本机已验证设置与核心交互；新增右键入口在原生窗口通过键盘菜单事件（Shift+F10）验证。物理鼠标右键的自动验证受透明窗口穿透限制，仍待实用验收；多显示器、跨DPI及极快点击穿透未完成专项验证。实际观感由使用者验收。
