# v0.3.0 动画检查

2026-11-04，使用 Windows 上 DSH Desktop 0.2.1-rc.5 自带的真实运行时，在隔离 Web profile 和匹配 Electron 44.7.0 客户端检查。

## 播放

动画采用九个生成的关键姿态，通过小网格变形和短时间纹理混合补充过渡。头、手、饭碗和尾巴有连续位移。短混合区间用于控制绘制姿态之间的轮廓重影。

独立动作循环约 38 秒测得 30.00 FPS。DSH 客户端的 5 秒样本为 29.94 FPS，连续捕获的 30 张画面全部不同。夹饭、入口、咀嚼、偷瞄、擦嘴、满足和打盹均在独立播放中出现，点击后护碗。

实际检查了浅色、深色和 112 × 112 CSS 像素的人物画面。演示 GIF 从真实客户端画布录制的 VP9 视频转换，GIF 使用 30 FPS 的平均时序，单帧时长受 GIF 的百分之一秒精度限制。

## 资源

RGBA 纹理为 672 × 672，约 1.72 MiB。画布按屏幕像素比渲染，上限为 224 × 224。收起后释放纹理、程序和缓冲区，并将画布缩回 1 × 1。

以下为同一隔离实例的渲染器与 GPU 进程合计，每阶段采样 5 秒，启用正常硬件加速。

| 阶段 | 工作集 MiB | 私有提交 MiB | CPU 占单个核心 |
| --- | ---: | ---: | ---: |
| 首次展开前 | 329.33 | 295.03 | 2.86% |
| 展开播放 | 397.34 | 408.97 | 11.48% |
| 收起后 | 362.92 | 362.32 | 1.66% |
| 再展开、收起 4 次后 | 362.27 | 361.65 | 1.61% |

首次展开工作集增加约 68 MiB，私有提交增加约 114 MiB，包含浏览器、GPU 上下文和宿主分配。收起后部分浏览器缓存继续保留，四次额外展开与收起的样本没有继续增长。数值随设备、驱动和宿主活动变化，属于整进程采样。

## 暂停与回归

- 收起后动画帧计数停止，控制器清空，画布为 1 × 1。
- 触发页面可见性处理后帧计数停止，恢复可见后继续。该项在隔离客户端中模拟 `document.hidden` 和可见性事件。
- 在客户端通过媒体模拟开启“减少动态效果”后绘制停止。
- 设置保存成功关闭、错误保留表单、工资立即刷新、参数落盘、倒计时、鉴权、插件图标和事件记账回归检查通过。
- 费用链路使用合成 token 记录。缺失服务注入的负控被真实宿主拒绝。

WebGL 无法建立时显示静态人物。实际使用中的动画观感和其他 DSH 版本继续随反馈核对。
