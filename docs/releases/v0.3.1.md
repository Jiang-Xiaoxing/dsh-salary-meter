# SalaryMeter — v0.3.1（2026-11-06）

## 新功能

- **价格表覆盖 36 个模型**：除了 DeepSeek，现在也能估算 OpenAI、Anthropic Claude、Google Gemini、xAI Grok、智谱 GLM、通义 Qwen、Kimi、MiniMax、阶跃 Step 的调用花费。外国厂商按 7.15 汇率折算成人民币。
- **价格表自动更新**：插件启动时拉一次价格表，之后每 24 小时再拉一次。维护者更新 GitHub 上的 `prices.json` 后，所有用户下次打开 DSH 就会用上新价，不需要重装插件。拉不到时用本地缓存或内置价，不影响使用。

## 改进

- **挂件不再卡在侧栏**：修好了挂件在 DS Bot 里被渲染到左侧 Bot 栏底部、发灰拖不动的问题，现在正常浮在窗口上。
- **外观三档**：新增深色 / 浅白 / 暗金三种外观，设置页点一下立刻生效。
- **计价识别更准**：按模型名匹配官方价，同一个模型走官方账号还是网关（例如 opencode-go）都按同一份价格算。

## 修复

- 修复「偷吃估算（有遗漏）」误报：以前遇到不带模型名的请求会把当前模型清空，导致后面一串调用都算不出价、被标成遗漏。现在只有确实属于 DeepSeek、但价格表里没有的模型才会提示遗漏。
- 设置页标题从「工资参数设置」改为「设置」，保存后自动关闭。

## 安装

```text
github:Jiang-Xiaoxing/dsh-salary-meter#v0.3.1
```

老用户升级：把插件源里的 `#v0.3.0` 改成 `#v0.3.1` 重新添加即可。

默认月薪 5,000 元。金额按工资参数累计，模型饭钱为估算值，统计范围见 README。
